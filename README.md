# Book Store

Минимальный проект на Next.js App Router, React, TypeScript и SCSS.
Менеджер пакетов — pnpm.

## Разработка

```bash
pnpm install
pnpm dev
```

Откройте http://localhost:3000.

## Проверки и production

```bash
pnpm lint
pnpm build
pnpm start
```

Главная страница: `src/app/page.tsx`.
Стили страницы: `src/app/main.module.scss`.
Глобальные сбросы: `src/app/globals.scss`.
